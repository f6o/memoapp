# CLAUDE.md

## Project Overview

**memoapp** is a gRPC-based memo service written in Go. It provides a server that stores memos in SQLite and a CLI client for interaction.

## Tech Stack

- **Language:** Go 1.22+ (toolchain 1.23.7)
- **RPC Framework:** gRPC with Protocol Buffers (proto3)
- **Database:** SQLite3 (`github.com/mattn/go-sqlite3` - requires CGO)
- **Testing:** `github.com/stretchr/testify` (assertions + mocks)
- **CI:** GitHub Actions (`.github/workflows/go.yml`)
- **Containerization:** Docker (multi-stage build)

## Repository Structure

```
main.go                            # Server entry point
client/main.go                     # CLI client entry point
proto/memoapp.proto                # gRPC service & message definitions
server/
  server.go                        # gRPC server implementation
  server_test.go                   # Unit tests (testify mocks)
  repository/
    memo_repository.go             # SQLite data access layer
Makefile                           # Proto code generation
Dockerfile                         # Multi-stage Docker build
.github/workflows/go.yml           # CI pipeline
```

## Architecture

Layered architecture: **gRPC handlers** -> **Server** -> **Repository** -> **SQLite**

- `server.server` implements `proto.MemoServiceServer` with dependency-injected `MemoRepositoryInterface`
- `repository.MemoRepository` implements `MemoRepositoryInterface` with direct SQL queries
- Interface-based design enables mock testing without a real database

### gRPC Service (3 RPCs)

| Method | Request | Response |
|--------|---------|----------|
| `CreateMemo` | title, content | Memo |
| `GetMemo` | memo_id | Memo |
| `ListMemos` | (empty) | []Memo |

## Build & Development Commands

```bash
# Generate protobuf Go code (required before building)
make gen-proto

# Install dependencies
go mod tidy

# Run tests
go test -v ./...

# Build binaries
go build -o dist/memoapp-server ./main.go
go build -o dist/memoapp-client ./client/main.go

# Run server
./dist/memoapp-server

# Run client (dev mode, insecure)
./dist/memoapp-client --dev createMemo "Title" "Content"
./dist/memoapp-client --dev getMemo 1
./dist/memoapp-client --dev listMemos
```

### Prerequisites for Code Generation

Protoc compiler and Go gRPC plugins must be installed:

```bash
go install google.golang.org/protobuf/cmd/protoc-gen-go@latest
go install google.golang.org/grpc/cmd/protoc-gen-go-grpc@latest
```

## Environment Variables

|----------|---------|-------------|
| `DB_FILE` | `memos.db` | SQLite database file path |
| `LISTEN_ADDR` | `:50051` | Server listen address |
| `MEMOAPP_SERVER_ADDRESS` | `localhost:50051` | Client target server |
| `MEMOAPP_SERVER_CERTFILE` | (none) | TLS certificate for client |

## Testing

- Tests are in `server/server_test.go`
- Uses testify `mock.Mock` to mock `MemoRepositoryInterface`
- All 3 RPC methods have unit tests
- Run: `go test -v ./...`
- No integration tests currently exist

## CI Pipeline

Triggered on push/PR to `main`. Steps:
1. Install protoc and Go 1.23
2. Install gRPC codegen plugins
3. `make gen-proto`
4. `go mod tidy`
5. `go test -v ./...`
6. Build server and client binaries
7. Upload `dist/` as artifacts

## Key Conventions

- **Generated files are gitignored:** `proto/*.pb.go` files are generated by `make gen-proto` and not committed
- **Interface suffix:** Repository interfaces use explicit `Interface` suffix (e.g., `MemoRepositoryInterface`)
- **Error handling:** Standard Go `if err != nil` pattern throughout
- **Comments:** Some inline comments are in Japanese
- **No ORM:** Direct SQL queries with `database/sql`
- **Timestamps:** Stored as Unix seconds (int64) in both SQLite and protobuf
- **Constructor pattern:** `NewServer(repo)`, `NewMemoRepository(dbFile)` for initialization

## Docker

```bash
docker build -t memoapp .
docker run -p 50051:50051 memoapp
```

Multi-stage build: `golang:1.24-bullseye` (builder) -> `debian:bullseye-slim` (runtime). Only the compiled server binary is included in the final image.

## Important Notes

- Always run `make gen-proto` after modifying `proto/memoapp.proto`
- SQLite requires CGO enabled (`CGO_ENABLED=1`) for compilation
- The `memos.db` file and `cert.pem` are gitignored
- Client defaults to secure TLS; use `--dev` flag for insecure local development
